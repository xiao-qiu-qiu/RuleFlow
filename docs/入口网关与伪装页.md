# 入口网关与伪装页

把面板和订阅接口藏在随机入口路径下，其余路径返回一张无害的静态页（伪装页）。
目的是让域名被扫描、被人随手打开时看不出这是订阅管理面板，降低整个域名被按 SNI 或按域封禁的概率。

面板入口和订阅入口是**两个彼此独立的随机段**：订阅地址要发给别人，泄露它不应该连带泄露面板。

## 行为

设 `RF_ENTRY_PATH=/7f3a9c2b`（面板入口）、`RF_SUB_PATH=/9cf499ddfc`（订阅入口）之后：

| 请求 | 结果 |
| --- | --- |
| `GET /7f3a9c2b` 或 `/7f3a9c2b/...` | 去掉前缀后正常处理，并写入入口 cookie `rf_entry` |
| `GET /9cf499ddfc/subscribe`、`/universal-sub`、`/rulesets/*`、`/convert` | 去掉前缀后正常处理，**不写 cookie** |
| `GET /9cf499ddfc/` 或其他面板路径 | 返回伪装页（拿到订阅地址进不了面板） |
| 带有效 `rf_entry` cookie 的其他路径 | 正常处理（面板前端跳转、`/api`、`/assets` 都靠这条放行） |
| `GET /health` | 正常处理（探活豁免） |
| 其他路径（`/`、`/login`、`/version`、`/subscribe` …） | 返回伪装页（`cover/index.html`，编译进二进制） |
| 其他路径且看起来是静态资源（`.js` / `.css` / `.ico` / `.txt` …） | 返回 404，避免“把 HTML 当图片返回”这种不自然行为 |

两个变量都留空时整个网关关闭，行为与旧版本完全一致；只设 `RF_ENTRY_PATH` 时订阅与面板共用同一条入口路径（旧行为）。

`RF_SUB_PATH` 的放行清单固定在代码里（`subscriptionDeliveryPaths` / `subscriptionDeliveryPathPrefix`），
要加减路径改 `entry_gate.go`。

### 为什么面板入口用 cookie 而不是纯路径前缀

面板前端（React + BrowserRouter）跳转和接口请求用的都是绝对路径（`/dashboard`、`/api/...`、`/assets/...`）。
如果只靠“请求路径带前缀才放行”，浏览器一跳出前缀就会撞到伪装页。首次通过面板入口访问时写一个
`rf_entry` cookie（`HttpOnly`、`SameSite=Lax`、HTTPS 下带 `Secure`，30 天），后续请求凭它放行，
这样不需要改动前端，也不需要反代做路径重写。订阅入口刻意**不写**这个 cookie。

入口和 cookie 都是“知道 URL 就能进”的弱凭据，真正的鉴权仍然是面板自身的登录会话；
入口路径与订阅 token 一起构成“不要外传”的信息。

### 复制出来的链接为什么能直接用

服务端会把带前缀的公开地址注入 SPA HTML（`window.__RF_PUBLIC_BASE__`，取自 `PUBLIC_BASE_URL`，
见 `injectPublicBase`），前端的复制按钮统一走 `src/lib/public-url.ts` 的 `publicUrl()` 拼接。
所以 `PUBLIC_BASE_URL` 必须写成**带订阅入口前缀**的地址（例如 `https://panel.example.com/9cf499ddfc`），
否则面板里复制出来的订阅 / 规则集 / 转换链接会缺前缀而 404。

### 改动过的既有行为

- 原先无需登录的公开接口（`/convert`、`/api/templates/public*`、`/converter` 页面）也会被网关挡在外面，
  只有带入口 cookie 的浏览器能访问。如果需要保留真正公开的转换入口，在 `entry_gate.go` 的放行分支里为这些路径加豁免。
- `/health` 保持公开，便于容器与外部探活。它只返回服务状态，不含面板特征。

## 反向代理要求

- 反代**不要**剥掉前缀，直接把原始路径转给应用（网关自己剥）。
- 透传 `X-Forwarded-Proto` 与 `X-Forwarded-Host`，否则 cookie 的 `Secure` 属性与绝对 URL 会判断错误。
- `PUBLIC_BASE_URL` 要写成带前缀的公开地址，例如 `https://panel.example.com/7f3a9c2b`，
  订阅串里的 `#!MANAGED-CONFIG`、`/rulesets/...` 与分享链接都会带上它。

## 相关配置

```env
RF_ENTRY_PATH=/7f3a9c2b
RF_SUB_PATH=/9cf499ddfc
RF_ENTRY_COOKIE=            # 留空则由 RF_ENTRY_PATH 派生
PUBLIC_BASE_URL=https://panel.example.com/9cf499ddfc
```

伪装页在 `cover/index.html`，通过 `//go:embed cover` 编译进二进制，改完需要重新构建。
